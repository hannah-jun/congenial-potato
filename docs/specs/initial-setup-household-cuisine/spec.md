# 초기 설정: 가구 인원수 · 요리 취향

## 사용자에게 보이는 결과

앱을 처음 열면 가구 인원수와 요리 취향을 고르는 초기 설정 화면이 먼저 보인다.
설정을 마치면 추천 화면으로 넘어가고, 이후 앱을 다시 열어도 그 설정이 유지된
채 바로 추천 화면이 보인다. 추천 화면에서는 언제든 설정을 다시 열어 인원수나
취향을 바꿀 수 있고, 바꾸면 추천 레시피 목록과 비용 코멘트가 새 설정 기준으로
다시 계산되어 보인다.

## 승인된 범위

- 가구 인원수(2인/3인/4인)와 요리 취향을 고르는 초기 설정 화면을 만든다.
- 설정값을 기기에 저장해 다음 방문에도 유지한다.
- 추천 화면에 설정을 다시 열어 바꿀 수 있는 진입점을 추가한다.
- 설정된 요리 취향과 일치하는 레시피만 추천 목록에 남긴다.
- 설정된 가구 인원수에 비례해 추천 레시피의 예상 비용 코멘트를 조정한다.

카테고리 목록과 재설정 가능 여부의 구체적인 값과 이유는
[initial-setup-preferences](../../decisions/initial-setup-preferences.md) 결정을
따른다.

## 관찰 가능한 인수 기준

- 설정을 아직 마치지 않은 상태로 앱을 열면, 추천 화면 대신 가구 인원수·요리
  취향을 고르는 초기 설정 화면이 보인다.
- 초기 설정 화면에서 인원수와 취향을 모두 고르기 전에는 설정을 완료할 수
  없다.
- 초기 설정을 완료하면 추천 화면으로 넘어간다.
- 앱을 닫았다 다시 열어도 초기 설정 화면이 다시 나타나지 않고, 이전에 고른
  설정이 그대로 반영된 추천 화면이 바로 보인다.
- 추천 화면에는 현재 설정된 인원수·취향을 확인하고 바꿀 수 있는 진입점이
  있다.
- 설정에서 취향을 바꾸면, 선택한 취향과 일치하지 않는 레시피는 추천 목록에서
  사라진다.
- 설정에서 인원수를 바꾸면, 각 추천 레시피 옆 예상 비용 코멘트가 바뀐
  인원수에 비례해 다시 계산되어 보인다.
- 선택한 취향으로 조건(저렴한 재료 2개 이상 포함)을 만족하는 레시피가 하나도
  없으면, 오류 화면이 아니라 기존과 동일하게 "이번 주는 추천할 레시피가
  없어요" 같은 안내 문구가 표시된다.

## 정해진 제약과 이유

- 요리 취향 카테고리 목록과 가구 인원수·취향의 재설정 가능 여부는
  [initial-setup-preferences](../../decisions/initial-setup-preferences.md)
  결정을 따른다 — 재검토가 필요하면 스펙이 아니라 그 결정 기록을 갱신한다.
- 저렴한 재료 판정 기준과 추천 레시피 자격 조건(저렴한 재료 2개 이상)은
  [cheap-ingredient-recommendation-criteria](../../decisions/cheap-ingredient-recommendation-criteria.md)
  결정을 그대로 따르고 이번 단위에서 바꾸지 않는다 — 취향 필터는 그 위에
  얹는 추가 조건일 뿐, 기존 "2개 이상 조합" 약속을 흔들지 않는다.

## 가정 (뒤집을 수 있음)

- 설정값은 이 기기/브라우저에 저장되어 유지된다고 가정한다. 로그인 없는
  개인용 도구이므로 여러 기기 간 동기화는 다루지 않는다.
- 기존 시드 레시피의 예상 비용은 2인 기준으로 산정되어 있다고 보고, 실제
  설정된 인원수 비율(인원수 ÷ 2)만큼 곱해 조정한다.
- 조리 시간은 인원수에 따라 달라지지 않는다고 가정하고 그대로 표시한다.
- 가격 데이터는 농수산물 위주로 한정된다고 가정한다. 조미료·가공식품처럼
  가격 추적 대상이 아닌 재료는 이미 갖춰져 있다고 보고, 이번 단위에서 시드
  가격 데이터를 인위적으로 늘리지 않는다.
- 초기 설정 화면에는 인원수·취향 어느 쪽도 기본 선택값을 두지 않는다 —
  사용자가 직접 고르기 전까지는 설정을 완료 처리하지 않는다.

## 범위 밖 (이 단위에는 포함 안 함)

- 취향 다중 선택(여러 취향을 동시에 반영) — PRODUCT.md도 단일 취향 설정을
  전제로 하며, 다중 선택은 필터링 로직과 UI를 이번 단위 밖으로 복잡하게
  만든다.
- 가구 인원수 세분화(5인 이상, 소수 단위 등) — PRODUCT.md가 2/3/4인만
  명시한다.
- 저렴한 재료를 장바구니 목록에 담는 기능 — 다른 작업 단위에서 별도로 진행
  중이며, 그 작업이 수정 중인 화면과의 충돌을 피하기 위해 이번 단위는 손대지
  않는다.

## 남겨둔 리스크

- 시드 레시피가 4개뿐이고 대부분 한식이라, 중식·양식·일식을 고르면 추천
  결과가 거의 항상 빈 상태로 보일 수 있다 — 실제 데이터로 확인이 필요하다.
- 취향 필터와 "저렴한 재료 2개 이상" 조건이 함께 적용되면 조건을 만족하는
  레시피가 더 드물어져, 빈 상태가 실제로 얼마나 자주 나타나는지는 구현 후
  확인이 필요하다.
