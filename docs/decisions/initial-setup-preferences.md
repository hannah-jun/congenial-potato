# 초기 설정(인원수·취향) 기준

## Decisions

- 요리 취향 카테고리는 한식/중식/양식/일식 네 가지로 고정한다.
- 가구 인원수(2인/3인/4인)와 요리 취향 모두, 최초 설정 후에도 재설정 화면을
  통해 언제든 바꿀 수 있다.

## Boundaries

- 이 기준은 "초기 설정" 기능과 그 값을 사용하는 후속 기능(추천 필터링, 비용
  스케일링 등)에 공통으로 적용된다.
- 레시피 데이터에 새 항목을 추가할 때는 이 네 카테고리 중 하나로 취향 태그를
  달아야 한다.

## Why

취향 카테고리는 PRODUCT.md의 예시(한식/중식)를 실제로 구분 가능한 수준으로
확장한 것이다. 인원수와 취향을 동일하게 "언제든 변경 가능"으로 정한 이유는,
PRODUCT.md가 인원수와 취향을 같은 초기 설정 단계로 묶어 소개하고 있어 한쪽만
바꿀 수 있게 하면 사용자 입장에서 일관성이 없고, 초기 입력을 잘못했을 때
되돌릴 방법이 없어지기 때문이다.

## Reconsider when

- 시드 레시피가 늘어난 뒤에도 특정 취향 카테고리(중식/양식/일식)로 추천 가능한
  레시피가 계속 없어서 그 카테고리가 사실상 무의미한 경우.
- 인원수·취향을 자주 바꾸는 사용 패턴이 없어 "언제든 변경" 진입점이 불필요한
  복잡도로 판단되는 경우.

## Still-rejected alternatives

- 취향 카테고리를 한식/양식 두 개로 최소화 — 시드 데이터 규모에는 맞지만
  PRODUCT.md 예시(한식/중식)에 있는 중식을 빼면 실제 사용 취향을 반영하지
  못함.
- 가구 인원수는 최초 설정 후 고정 — PRODUCT.md가 인원수·취향을 같은 초기
  설정 단계로 묶어 다루므로, 취향만 변경 가능하게 하면 일관성이 깨짐.
- 양식 레시피 매칭을 위해 파스타·치즈 등을 시드 가격 데이터에 추가 — 실제
  가격 데이터 소스는 농수산물 중심일 가능성이 크다는 전제와 맞지 않아 채택
  안 함. 대신 가격 추적을 농수산물로 한정하고, 그 외 재료는 이미 갖춰져
  있다고 가정하기로 함(관련:
  [initial-setup-household-cuisine spec](../specs/initial-setup-household-cuisine/spec.md)).
